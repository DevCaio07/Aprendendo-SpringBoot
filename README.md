# 📖 Sobre o projeto

O **Fridge API** foi criado como projeto de estudos com o objetivo de aprender, na prática, o desenvolvimento de APIs REST utilizando o ecossistema Spring Boot.

Durante o desenvolvimento do projeto estou colocando em prática conceitos importantes do desenvolvimento Backend, como organização em camadas, persistência de dados e integração com banco de dados relacional. O Spring Boot simplifica a criação de aplicações Java ao fornecer configurações prontas e uma estrutura voltada para produtividade. :contentReference[oaicite:0]{index=0}

# 🛠️ Como executar

### Clone o projeto

```bash
git clone https://github.com/DevCaio07/Aprendendo-SpringBoot.git
```

Entre na pasta

```bash
cd Aprendendo-SpringBoot
```

Configure o arquivo

```properties
application.properties
```

Exemplo:

```properties
spring.datasource.url=jdbc:mysql://localhost:3306/fridge

spring.datasource.username=root

spring.datasource.password=senha

spring.jpa.hibernate.ddl-auto=update
```

Execute

```bash
./mvnw spring-boot:run
```

ou

```bash
mvn spring-boot:run
```
